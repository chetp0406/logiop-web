Overview

Logiop

A modern framework designed to bring the power and elegance of state machines into everyday software development — and to provide clarity for brainstorming or organizational tasks. Well‑crafted state machines can replace long hours of sifting through code and writing test stubs, helping optimize the development lifecycle. Logiop strives to be a true implementation of visual coding, empowering developers to move seamlessly from design to runtime. It consists of the following two core components:

Designer

A Progressive Web Application (PWA) that runs in the browser or can be installed as an app. Once installed, it can be used offline. It relies on the File System Access API to read and write files within a designated workspace folder on the local file system. All data remains local; no files are transmitted to external services. It graphs hierarchical state machines based on the Unified Modeling Language (UML). The Designer is not limited to software developers — it can be valuable for anyone exploring the clarity and discipline of state machines.

Every user always has access to the latest version of the Designer — a single, unified edition. Features are unlocked through the editions listed below.

Pulse Processor

A .NET Standard library that executes the code graphs produced by the Designer, enabling runtime execution of state machines in real applications. It handles the heavy lifting of execution semantics, leaving developers to focus on implementing behaviors: entry/doActivity/exit actions of state vertices, and guards/effects of transitions. Pulse is lightweight, asynchronous, and high‑performance, based on the Precise Semantics for State Machines (PSSM) 1.0 standard. It supports both high‑level and low‑level state machines — from user interface flows and application logic to detailed algorithmic execution.

Features

Design

Hierarchical state machines with key features including reusable behaviors, deep nesting of state vertices, prioritized orthogonal regions, submachines with connection point references, and auto-routed transitions.

Validate

Validate state machines against both custom rules and standards-based criteria to ensure structural and execution integrity.

Simulate

A state-of-the-art simulator powered by the Pulse processor enables thorough analysis of events and behaviors during execution.

Export

Share designs via SCXML and other interoperable formats.

Generate Code

Produce compact code graphs that serve as input for execution by the Pulse processor.

Execute

Run asynchronous state machines with the Pulse Processor embedded in your real application.

Supported Platforms

Designer

The Logiop designer is supported only on desktop browsers, and is not intended for use on mobile devices or tablets. The designer is supported on Microsoft Edge, Google Chrome, and other Chromium-based browsers. Safari and Firefox are not currently supported.

Pulse Processor

In its current version, Pulse runs in any .NET environment that supports the .NET Standard library — including Blazor, WPF, MAUI, Unity, ASP.NET, and the broader .NET stack.
